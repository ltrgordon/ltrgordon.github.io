How to play

Guess the hidden sequence of N colored pegs (up to 7). Tap a peg slot, then tap a color. Press Submit:
  • Black: right color in the right spot
  • White: right color, wrong spot
Hint reveals the color of a random secret peg. When solved, the secret code reveals on top.

Settings

Feedback: black = correct color + position, white = correct color wrong position. Order is not positional.
Hint reveals the color of one random peg (position stays hidden until solved).

2-player: Set the secret code

Player 1: Tap colors to set the code. Then press Lock code and hand the phone to Player 2.
If duplicates are disabled, you can’t repeat a color.
