How to play

Guess the hidden sequence of N colored pegs (up to 7). Tap a peg slot in your current guess, then tap a color. Press Submit to get feedback:
  • Black: right color in the right spot
  • White: right color, wrong spot
Use Hint to reveal the color of a random secret peg. When you solve it, the secret code reveals on top.

2-player: Set the secret code

Player 1: Tap colors to set the code. Then press Lock code and hand the phone to Player 2.
Tip: If duplicates are disabled, you can’t repeat a color.
